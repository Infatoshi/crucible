Implemented a working round-1 quantization baseline in [solution.py](/tmp/crucible_2ysop95f/solution.py) using `bitsandbytes` 4-bit NF4 + double quantization.

Key points:
- `load_model(device="cuda")` loads `Qwen/Qwen3-4B` quantized and returns a causal LM with standard `model(input_ids).logits`.
- `get_compressed_size()` returns an honest byte count from the loaded quantized model tensor storage (with deduplicated shared storages).
- Fallback size (if queried before load) is a conservative 4-bit estimate (`fp16_bytes // 4`).
